## 一、簡介

智慧系統需要整合感測、辨識、追蹤、決策與控制，才能根據環境變化採取適當行動。單張影像辨識可以找出物件的位置，但若目標持續移動、遭到遮擋，或同時出現多個外觀相似的個體，就需要加入時間資訊與追蹤機制。當固定動作無法持續達成目標時，還需要利用回饋調整策略。

本報告以課堂涉及的技術為主，整理物件偵測與模型訓練、多目標追蹤、強化學習與閉環控制，以及多感測器融合與邊緣運算。內容依課堂資料歸納；參考文獻用於核對技術名稱與基本概念，不延伸討論課堂未介紹的演算法細節。

## 二、技術內容

### （一）物件偵測與模型訓練

#### 1. YOLO 物件偵測

物件偵測同時處理物件類別與位置。YOLO 透過神經網路輸出物件的邊界框及類別相關資訊，適合需要即時處理的影像系統。[1] 課堂涉及 YOLOv5n、YOLOv8n、YOLOv10n、YOLOv11n、YOLOv12n 與 YOLOv26n，其中不同版本的訓練及比較結果，需放在相同資料與流程下評估，不能直接推論某一版本在所有情境都較好。

辨識結果可設定信心值門檻，篩選需要保留的目標。評估模型時，除了觀察 mAP、Precision 與 Recall，也要考慮 FPS、推論延遲、參數量及功耗。準確度與運算效率需配合部署平台及任務需求一起判斷。

#### 2. 三階段訓練

| 階段 | 方法 | 主要目的 |
|---|---|---|
| 第一階段 | 監督式學習 | 利用人工標註資料建立初始模型 |
| 第二階段 | 半監督學習與偽標籤 | 利用未標註資料擴充訓練，降低人工標註需求 |
| 第三階段 | 增量微調 | 新增類別，同時保留既有辨識能力 |

偽標籤由老師模型預測產生，再保留高信心結果供後續學習。這種方法能減少人工工作，但效益取決於標籤品質。錯誤偽標籤可能使學生模型學到錯誤資訊，形成確認偏誤，因此不能只追求增加資料數量。

學習新類別時，模型可能忘記原本已學會的類別。凍結部分網路層、降低學習率及調整偵測頭，是課堂涉及的微調方式。背景影像與非目標影像也能納入訓練，協助降低誤判。

### （二）多目標追蹤與個體重新辨識

#### 1. 跨影格維持個體 ID

多目標追蹤將不同影格中的偵測結果連結起來，並維持每個目標的個體 ID。與單張偵測相比，追蹤加入時間上的連續資訊，可用來觀察移動軌跡與停留情況。

遮擋、快速移動與外觀相似都可能造成追蹤困難。目標重新出現後若無法維持原 ID，軌跡便容易被切成多段；目標之間的 ID 交換，也會降低追蹤穩定度。

#### 2. BoT-SORT 與 Re-ID

BoT-SORT 結合運動與外觀資訊進行目標關聯。[2] Re-ID（重新辨識）利用外觀特徵協助區分個體，餘弦距離則可用於比較特徵向量。課堂也比較了 BoT-SORT 與 ByteTrack 的軌跡數及平均軌跡壽命。

| 技術或指標 | 課堂重點 |
|---|---|
| BoT-SORT | 維持個體 ID，改善多目標追蹤 |
| Re-ID | 利用特徵區分外觀相似的個體 |
| 餘弦距離 | 比較個體特徵的差異 |
| 軌跡數 | 觀察追蹤是否容易中斷、產生多段軌跡 |
| 平均軌跡壽命 | 觀察個體 ID 能持續維持多久 |
| 連續影格判斷 | 利用多張影格穩定目標判斷 |

軌跡數與壽命必須在相同場景條件下比較。課堂另提出以 MobileNet-V3 降低 Re-ID 運算量，以及非同步處理、條件式特徵擷取等改善方向，這些屬於後續規劃。

### （三）強化學習、閉環控制與座標校正

#### 1. DDPG 與自適應決策

DDPG 的全名為 Deep Deterministic Policy Gradient，是用於連續控制的深度強化學習方法。[3] 課堂以狀態、動作及獎勵函數說明策略如何根據環境反應調整。

| 要素 | 內容 |
|---|---|
| 狀態 | 軌跡、速度、與區域邊界的距離、群體密度 |
| 動作 | 水平與垂直角度、功率及執行模式 |
| 獎勵 | 達成目標的效果、能耗與重複模式的懲罰 |

固定策略每次採用相同路徑；隨機策略增加動作變化；自適應策略則依據環境反應調整動作。抗習慣化的重點是觀察效果如何隨時間改變，再調整策略，避免只重複既有模式。獎勵函數中的權重需與評估目標配合，課堂展示的權重屬於示例值。

#### 2. 閉環控制與模組化

閉環系統包含感知、決策、行動及回饋。感測器取得資訊後，辨識與決策模組產生控制指令，再由新的感測結果確認執行狀況。系統不是只下達一次命令，而是持續更新與修正。

模組化架構可分為感測、前處理、智慧決策、執行及人機介面等層級。各層可分別替換與量測，方便逐步改善。MQTT 用於傳送控制指令；Flask、Vue 與 Web HMI 則提供即時影像、歷史回放、事件紀錄與校正操作。

#### 3. 像素座標與控制角度的映射

影像位置與馬達角度需要透過校正建立關係。校正時先轉動設備、記錄光點位置，再使用最小平方法擬合一次或二次多項式，將像素座標換算成水平及垂直角度。

校正品質可透過 RMSE 評估。除了擬合誤差，也需分析資料點數量、分布及係數變化的影響。若校正點只集中在畫面中央，邊緣區域的誤差可能較大，因此資料點的分布也是重要因素。

### （四）多感測器融合與邊緣運算

#### 1. RGB 與熱成像的互補

RGB 影像提供顏色、紋理與外觀細節，但容易受到光線、反光與遮擋影響。熱成像提供熱輪廓，適合補強夜間與局部可見目標的觀察，但解析度較低，也可能受到曬熱物體干擾。

融合方式可依資訊整合的位置分為三類：

| 融合方式 | 做法 | 優點與限制 |
|---|---|---|
| 像素層級 | 將影像組成多通道輸入 | 保留較多資訊，但要求精準對齊 |
| 特徵層級 | 各自擷取特徵後合併 | 可學習互補特徵，但運算較重 |
| 決策層級 | 各自判斷後再整合結果 | 容易沿用現有模型，但一方漏判時較難補救 |

熱影像 ROI 搭配 RGB 確認，再利用連續影格與追蹤維持判斷，是課堂涉及的融合流程。融合的目的在於利用感測資訊互補，而非認為熱成像能穿透枝葉。

#### 2. 時間同步與空間配準

不同鏡頭的幀率、曝光、延遲、視角及解析度可能不同，融合前需先完成時間與空間上的對齊。

- **時間同步：**統一時鐘、校正延遲、排除重複影格及 FFC 凍結影格，再進行最近影格配對。
- **空間配準：**使用加熱棋盤格等共同標記，透過 Homography 單應性轉換建立座標對應。

時間戳記精度與實際影格配對時間差不同。RGB 為 30 FPS 時，最近影格配對仍可能有約 ±16.7 ms 時差。當目標快速移動，就會出現位置偏差；提高幀率、縮短曝光、時間內插及卡爾曼位置預測，都是可考慮的改善方式。

#### 3. 邊緣端與雲端分工

邊緣端負責即時偵測、追蹤與決策，雲端或後台負責資料儲存、模型再訓練與歷史分析。Jetson Orin 與 Raspberry Pi 5 是課堂涉及的運算平台，CSI 與 USB 則用於鏡頭連接。

大範圍無線圖傳需考慮距離、即時性與成本。將分析移到裝置端，可減少即時任務等待影像回傳的需求。部署時仍需綜合評估推論速度、延遲、功耗及裝置資源。

### （五）技術評估與實驗設計

評估指標需對準實際問題，各模組也需分別量測。辨識準確、追蹤穩定及控制有效是不同層面的能力，不能只用單一數字代表整體成效。

| 評估面向 | 指標或方法 |
|---|---|
| 物件偵測 | mAP、Precision、Recall、漏判與誤判 |
| 追蹤穩定度 | 軌跡數、平均軌跡壽命、ID 交換 |
| 校正精度 | 角度／像素誤差、RMSE |
| 即時部署 | FPS、延遲、功耗 |
| 持續成效 | 成效隨時間的變化、停留時間 |
| 公平比較 | 固定資料、硬體、場域及評估流程 |
| 穩健性 | 校正點數、分布及係數擾動的敏感度分析 |
| 統計分析 | 重複量數變異數分析（RM-ANOVA）、Tukey HSD 事後檢定 |

研究可先建立最小可行閉環，再逐一升級模組，確認改善來源。若同時更換多個模組，便較難釐清結果差異來自哪一項改動。

## 三、心得

這次課程讓我理解，智慧系統需要將辨識、追蹤、決策與控制串接，才能持續回應環境變化。我印象最深的是偽標籤與增量學習，因為增加資料或新增類別不一定能改善模型，仍要注意標籤品質與原有能力是否保留。另外，雙鏡頭融合也需要處理時間同步及空間配準，不能只把影像放在一起。未來進行研究時，我會先建立可運作的最小系統，再逐一改善模組，並選擇對應的指標進行公平比較，讓結果能說明改善的原因。
