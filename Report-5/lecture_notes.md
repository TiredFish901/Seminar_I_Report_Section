## 一、物件偵測與模型訓練

### 1. YOLO 物件偵測

物件偵測用來判斷影像中「有什麼物件」及「物件在哪裡」。YOLO 的輸出包含物件類別、邊界框與信心值，可用於即時影像分析。信心值門檻決定哪些偵測結果被保留，但信心值高不代表一定判斷正確。

常用評估指標包括 **Precision（精確率）**、 **Recall（召回率）** 與 **mAP（平均精確度均值）** 。Precision 著重偵測結果是否正確，Recall 著重實際目標是否被找出；即時應用還需要考慮 FPS、延遲與運算資源。

### 2. 監督式、半監督與增量學習

| 技術 | 原理與用途 |
|---|---|
| 監督式學習 | 使用人工標註的影像與答案訓練模型 |
| 半監督學習 | 同時利用已標註及未標註資料，降低人工標註需求 |
| 偽標籤 | 由老師模型預測未標註影像，將篩選後的結果作為訓練標籤 |
| 資料增強 | 改變影像呈現方式，增加訓練樣本的變化 |
| 背景／負樣本 | 加入不含目標的影像，協助模型降低誤判 |
| 增量微調 | 在既有模型上學習新類別，並保留原本的辨識能力 |
| 凍結模型層、低學習率 | 限制參數更新幅度，降低微調對既有能力的影響 |

偽標籤必須重視品質。錯誤預測若被當成正確答案反覆訓練，可能形成**確認偏誤**，使模型表現下降。新增類別時也需檢查既有類別的能力是否退化，這類現象稱為**災難性遺忘**。凍結部分網路層可限制參數變動，但不能保證完全避免遺忘，仍需重新評估舊類別的表現。


## 二、多目標追蹤與個體重新辨識

### 1. 偵測與追蹤的差異

物件偵測判斷單張影像中的目標；目標追蹤則將不同時間的偵測結果連結起來，判斷是否為同一個物件，並維持其 ID。每一幀偵測框的排列順序可能改變，不能直接把框的順序當成個體身分。因此，追蹤可提供移動軌跡、速度及停留時間等資訊。

多目標追蹤的困難包括遮擋、快速移動及外觀相似。若目標重新出現時被分配不同 ID，軌跡便會中斷；若兩個目標的 ID 被交換，也會影響後續控制。

### 2. BoT-SORT、Re-ID 與位置預測

| 技術 | 原理與用途 |
|---|---|
| BoT-SORT | 結合運動資訊與外觀資訊，進行多目標追蹤 |
| Re-ID（重新辨識） | 比較外觀特徵，協助確認目標是否為同一個體 |
| 餘弦距離 | 衡量特徵向量的相似程度，輔助目標配對 |
| 卡爾曼濾波 | 根據先前狀態預測位置，再利用新觀測修正 |
| 連續影格判斷 | 利用時間上的一致性，提高判斷穩定度 |

追蹤評估可觀察**軌跡數、平均軌跡壽命及 ID 交換**。在相同資料與偵測條件下，軌跡較完整、ID 交換較少，通常代表追蹤較穩定；也需避免將不同個體錯誤合併。
