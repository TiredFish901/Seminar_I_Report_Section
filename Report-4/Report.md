## 一、簡介

綠色科技以節能減碳、降低能源耗用與減少污染為目標，涵蓋能源、交通、建築、照明及材料等領域。其核心是透過技術改善資源利用效率，並考量產品從製造、使用到回收的環境影響。

太陽能電池能將光能直接轉換成電能，是綠色能源的重要技術。不同材料與結構會影響電池的效率、成本、使用壽命及適用環境。染料敏化太陽能電池與鈣鈦礦太陽能電池，分別以染料及新型半導體材料吸收光能，提供不同的光電轉換方式。

本報告整理綠色科技的概念，說明兩種電池的材料、運作原理、應用方向與技術挑戰，並比較其與能源永續的關係。

## 二、技術

### 2.1 綠色科技的應用與評估

| 應用領域 | 主要內容 | 評估重點 |
|---|---|---|
| 綠色能源 | 太陽能等再生能源發電 | 發電效率、供電條件與環境影響 |
| 綠色交通 | 腳踏車、公共運輸及電動車 | 能源消耗、電池壽命與回收 |
| 綠色建築 | 節能設計與能源設備整合 | 建築用電、材料與使用需求 |
| 綠色照明 | LED 等高效率照明 | 照明效率、耗電量與壽命 |
| 綠色材料 | 降低製造與使用過程的環境負擔 | 材料來源、耐用性與回收處理 |

評估綠色科技時，除了設備運作期間的節能效果，也應考量材料取得、製造、運輸與廢棄處理。例如電動車的能源利用與污染表現，需要連同電力來源及電池生命週期一起分析。太陽能電池也需要考量製造耗能、長期發電量及回收方式。

### 2.2 染料敏化太陽能電池（DSSC）

#### 2.2.1 基本概念與材料

染料敏化太陽能電池（Dye-Sensitized Solar Cell, DSSC）利用染料分子吸收光能，再將激發電子注入半導體。O’Regan 與 Grätzel 於 1991 年發表以染料敏化二氧化鈦薄膜為基礎的代表性研究。[1]

典型液態電解液型 DSSC 包含以下元件：[1]

| 元件 | 主要作用 |
|---|---|
| 染料（Dye） | 吸收光能，使電子進入激發狀態 |
| 二氧化鈦（TiO<sub>2</sub>） | 提供染料附著表面，接收並傳輸電子 |
| 透明導電層 | 使光進入電池，同時收集與傳導電子 |
| 電解液（I<sub>3</sub><sup>−</sup>／I<sup>−</sup>） | 利用氧化還原反應協助染料再生 |
| 對電極 | 接收外部電路返回的電子，促進電解液的還原反應 |

I 代表碘，I<sub>3</sub><sup>−</sup> 為三碘離子，I<sup>−</sup> 為碘離子。這是一種常見的電解液氧化還原對；其他 DSSC 也可能使用不同配方。

#### 2.2.2 發電原理

1. **染料吸光**：染料吸收光子，電子進入激發狀態。
2. **電子注入**：激發電子注入 TiO<sub>2</sub>，染料因失去電子而被氧化。
3. **電子輸出**：電子經 TiO<sub>2</sub> 與透明導電層進入外部電路，供應負載。
4. **染料再生**：電解液中的碘離子提供電子，使氧化後的染料恢復原態。
5. **電解液再生**：返回對電極的電子參與三碘離子的還原，完成循環。

**流程：染料吸光 → 電子注入半導體 → 外部電路輸出電流 → 染料與電解液再生。**

DSSC 的特色是將吸光與主要電子傳輸功能分別交由染料及半導體完成。若電子在輸出前發生復合，便會降低有效電流，因此染料設計、界面與電荷傳輸也是重要研究項目。[1]

#### 2.2.3 應用與限制

染料的吸收特性可透過分子設計調整，提供色彩與透光設計的可能性。特定 DSSC 已在室內環境光下展示發電能力，可作為低功耗裝置的能源來源研究方向。[2]

實際供電能力取決於光照強度、光譜、電池面積與負載功耗。室內光能利用仍需配合能源管理，不能直接推論一般手機可單靠教室照明完成充電。液態電解液型電池也需考量封裝密封性、電解液流失及長期性能維持。

### 2.3 鈣鈦礦太陽能電池（Perovskite Solar Cells）

#### 2.3.1 基本概念與結構

鈣鈦礦太陽能電池利用具有鈣鈦礦晶體結構的材料作為吸光層。太陽能領域常用的是金屬鹵化物鈣鈦礦，其薄膜吸收光能後產生電荷，再透過電池內其他材料引導電荷輸出。[3]

「鈣鈦礦」在此主要指材料的結構類型，不代表吸光材料一定含有鈣與鈦。典型元件包含透明導電電極、電子傳輸層、鈣鈦礦吸光層、電洞傳輸層及另一側電極；傳輸層的排列可因元件設計而不同。

| 元件 | 主要作用 |
|---|---|
| 鈣鈦礦吸光層 | 吸收光能並產生電子與電洞 |
| 電子傳輸層 | 選擇性收集並傳輸電子 |
| 電洞傳輸層 | 選擇性收集並傳輸電洞 |
| 電極 | 收集電荷並連接外部電路 |
| 封裝 | 保護元件，減少外部環境造成的劣化 |

#### 2.3.2 發電原理與發展方向

光照使吸光層產生電子與電洞，兩種電荷由相應的傳輸層收集，並經電極與外部電路形成電流。降低材料缺陷及界面的電荷復合，有助於提升輸出性能。

**流程：吸光層吸光 → 產生電子與電洞 → 傳輸層收集電荷 → 電極輸出電流。**

鈣鈦礦薄膜具有高效率與降低製造成本的潛力。部分製程可使用溶液塗布或低溫處理，但實際成本仍取決於製程良率、封裝及壽命。另一個方向是將鈣鈦礦與矽電池結合成疊層電池，讓不同吸光層利用不同波段的光，以提高整體光能利用率。[3]

#### 2.3.3 技術挑戰

- **穩定性與壽命**：水氣、氧氣、光照、熱及電壓等因素可能造成材料或元件劣化。
- **大面積製造**：需要維持薄膜均勻性與品質，減少小面積電池和大面積模組之間的性能差距。
- **環境影響**：含鉛配方需考量元件損壞後的鉛外洩，以及回收與處理方式。
- **性能驗證**：需要可比較的測試條件與長期資料，確認效率及耐用性。[4]

### 2.4 兩種太陽能電池的比較

| 比較項目 | 染料敏化太陽能電池 | 鈣鈦礦太陽能電池 |
|---|---|---|
| 吸光材料 | 染料分子 | 鈣鈦礦半導體薄膜 |
| 主要運作方式 | 染料注入電子，氧化還原介質完成再生 | 吸光層產生電荷，由傳輸層收集 |
| 應用方向 | 室內光能利用、色彩與透光設計 | 薄膜發電、與矽結合的疊層電池 |
| 研究重點 | 染料、電荷復合、電解液與封裝 | 薄膜品質、界面、穩定性與量產 |
| 永續考量 | 材料與電解液選擇、壽命及回收 | 含鉛配方管理、壽命及回收 |

兩種電池的價值需要依使用情境評估。室內低功耗裝置重視弱光下的能源供應；大規模發電則更重視長期發電量、耐用性與成本。單一效率數值不足以判斷技術是否適合實際應用。

## 三、心得

透過整理綠色科技與新型太陽能電池，我了解到節能減碳需要從材料、製造到回收的整個過程進行評估。染料敏化電池利用染料吸光，再透過半導體與電解液完成電荷傳輸，讓我看見材料分工的重要性；鈣鈦礦電池則呈現新材料在光電轉換上的潛力。不過，效率提升之外，穩定性、壽命與環境影響同樣重要。這也讓我體會到，研究成果要成為實用產品，必須結合使用需求與可靠性驗證。未來學習相關技術時，我會更重視原理與應用條件之間的關係。
